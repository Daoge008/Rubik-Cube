# 系统架构设计规范 (System Architecture Specification)

本项目是一款基于 **Flutter + C++ Native 引擎 (OpenCV / NDK)** 的 Android 实时魔方识别、求解与 AR 还原系统。

## 一、端到端数据流动与分层架构
1. **视觉感知层**: YOLOv8-OBB 检出魔方面姿态与 4 角点，通过透视变换展开为 300x300 正面，截断黑缝与高光采样 3x3 中心像素，通过动态中心色块物理锚定进行 CIELAB ΔE94 分类。
2. **状态聚合层**: 自由旋转连续识别，维护 8 帧滑动窗口多数表决，自动锁定 6 面并拼装 54 字符状态，进行群论 5 大守恒定律校验。
3. **离线双求解内核**: Kociemba 两阶段最少步求解引擎 (~20 步最优解) 与 CFOP 初学者 4 阶段教学引擎 (Cross -> F2L -> OLL -> PLL)。
4. **AR 空间投影与实时校验**: solvePnP 计算 6DoF 姿态，空间透视投影 3D 曲面引导箭头贴合真实魔方，实时检测用户拧法，校验匹配连续 5 帧自动触发跳步与触觉振动反馈。
