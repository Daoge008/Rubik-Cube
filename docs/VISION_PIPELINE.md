# 视觉识别与连续扫描管线 (Vision Pipeline)

1. **YOLOv8-OBB 旋转目标检测**: 基于 Roboflow 公开数据集训练导出端侧 TFLite 模型，直接输出倾斜魔方面的旋转边界框与 4 个有序角点。
2. **透视展开**: 通过 `cv::warpPerspective` 将倾斜面归一化为 300x300 正方形。
3. **色彩分类**: 在 CIELAB 色彩空间利用 CIE94 距离度量，动态使用 6 个中心块作为真实环境色温锚点（EMA 平滑更新），消除光照反光影响。
4. **多帧聚合**: 自由翻转魔方，滑动窗口投票锁定各面，集齐 6 面后自动拼合 54 色块。
