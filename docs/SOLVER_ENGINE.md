# 求解算法引擎与数学校验 (Solver Engine)

1. **54-Facelet 展开与守恒定律**:
   - 颜色计数（每种各 9 块）
   - 角块自转守恒 (sum(twist) % 3 == 0)
   - 棱块翻转守恒 (sum(flip) % 2 == 0)
   - 置换奇偶性守恒 (角块逆序数奇偶性 == 棱块逆序数奇偶性)
2. **Kociemba 两阶段算法**: IDA* 搜索将状态缩减至群 H，再由群 H 搜索至还原态，步数不超过 22 步。
3. **CFOP 教学流水线**: 底层白十字、F2L 4 组槽位、2-Look OLL 翻黄、2-Look PLL 换位，适合教学。
